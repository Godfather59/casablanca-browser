# Security Policy

## Supported versions

Security fixes are currently applied to the latest `0.2.x` development branch.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could expose browsing data, execute code, bypass navigation restrictions, or grant an untrusted page native permissions.

Use GitHub's private vulnerability reporting or security-advisory feature for this repository. Include:

- affected platform and Casablanca version
- reproduction steps
- expected and observed behavior
- logs or a minimal proof of concept, with secrets removed

The project is an early beta and has not yet completed an independent security audit. Avoid using it for highly sensitive accounts until the relevant platform has been reviewed.
